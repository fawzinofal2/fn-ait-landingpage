# fn-ait — الموقع الرسمي

موقع fn-ait (شركة برمجيات تطوّر تطبيقات هواتف ومواقع) مبني بـ Next.js 16 (App Router) + TypeScript + Tailwind CSS 4، وقاعدة بيانات SQLite عبر Prisma 7 لإدارة بيانات التطبيقات المنشورة (اسم التطبيق، الوصف، الصلاحيات، الإعلانات، المشتريات...)، والتي تُستخدم لتوليد صفحة تفاصيل كل تطبيق بالإضافة إلى **سياسة خصوصية وشروط استخدام مخصّصة تلقائيًا لكل تطبيق** — جاهزة للربط المباشر من متجر Google Play.

## التشغيل محليًا

```bash
npm install
npm run db:migrate   # ينشئ قاعدة البيانات المحلية ويطبّق المخطط
npm run db:seed      # يزرع بيانات تجريبية (تطبيق Puzzloop)
npm run dev          # http://localhost:3000
```

## البنية

- `src/app` — صفحات Next.js (الرئيسية، تطبيقاتنا، من نحن، تواصل معنا، وسياسات الخصوصية/الاستخدام العامة والخاصة بكل تطبيق).
- `src/lib/policy.ts` — يولّد نصوص سياسة الخصوصية وشروط الاستخدام **ديناميكيًا** بناءً على بيانات كل تطبيق (هل يحتوي إعلانات؟ مشتريات داخلية؟ يستهدف الأطفال؟ ...) بدل كتابتها يدويًا لكل تطبيق.
- `prisma/schema.prisma` — نموذج بيانات `App` (تطبيق واحد لكل صف)، و`prisma/seed.ts` يحوي بيانات Puzzloop كمثال.
- عند إضافة تطبيق جديد: أضف صفًا جديدًا في `prisma/seed.ts` (أو عبر `prisma studio`)، وستُنشأ صفحاته وسياساته تلقائيًا على `/apps/<slug>`، `/privacy/<slug>`، `/terms/<slug>`.
